
# Budget25

This is a budget tracking app we built using Kotlin. It helps you manage your income and expenses, and lets you keep track of your balance easily. Everything runs locally using a Room database, and the app follows the MVVM structure to keep things clean and organized.

## How to run in Android Studio
- Clone the repository in the new project page.
- Wait for Android Studio to sync and download dependacies. 
- Press run.

## How to run using APK

- Download app-debug.apk to your phone
- Use Android Debug Bridge to install the APK
- ```adb install app-debug.apk ```
